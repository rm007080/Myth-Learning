# ギリシャの創世神話

ギリシャ神話の世界創造は、混沌から秩序へと進む壮大な物語です。主にヘシオドスの『神統記』に基づきます。

## 原初の状態

### カオス（混沌）
- 最初に存在した虚空
- 形も秩序もない状態
- すべての始まり

### 原初神の誕生

カオスから自然に生まれた神々：

1. **ガイア（大地）**
   - 自ら存在した大地の女神
   - すべての生命の母
   - 山々、海、神々を生む

2. **タルタロス（奈落）**
   - 地下の最深部
   - 後に罰せられた者の幽閉地

3. **エロース（愛）**
   - 原初の愛の力
   - 創造の原動力

4. **エレボス（暗黒）**
   - 原初の闇

5. **ニュクス（夜）**
   - 夜の女神
   - エレボスと共に多くの概念神を生む

## ウーラノスとガイアの時代

### ウーラノス（天空）の誕生
- ガイアが独力で生んだ息子
- ガイアの夫となる
- 天空を支配

### ティターン族の誕生

ガイアとウーラノスの12人の子供：

**男性ティターン**
1. **オーケアノス** - 大洋
2. **コイオス** - 知性
3. **クレイオス** - 天体
4. **ヒュペリーオン** - 光明
5. **イアペトス** - 技術
6. **クロノス** - 時間（最年少で最強）

**女性ティターン**
1. **テイアー** - 光輝
2. **レアー** - 豊穣
3. **テミス** - 正義
4. **ムネーモシュネー** - 記憶
5. **ポイベー** - 予言
6. **テテュス** - 養育

### その他の子供たち

**キュクロプス（単眼巨人）3人**
- ブロンテース（雷鳴）
- ステロペース（稲妻）
- アルゲース（閃光）
- 後にゼウスの雷電を作る

**ヘカトンケイル（百手巨人）3人**
- ブリアレオース
- コットス
- ギュエース
- 各々100本の腕と50の頭を持つ

## クロノスの反逆

### ウーラノスの暴政
- 醜い子供たち（キュクロプスとヘカトンケイル）をタルタロスに幽閉
- ガイアは苦しみ、子供たちに復讐を促す

### 去勢と権力奪取
- ガイアがアダマスの鎌を作る
- クロノスが父ウーラノスを待ち伏せ
- 去勢し、天と地を分離
- ウーラノスの血から：
  - **エリニュエス（復讐の女神）**
  - **ギガース（巨人族）**
  - **メリアス（樹木の精）**
- 切り落とされた性器が海に落ち、泡から**アプロディーテー**誕生

### クロノスの時代
- ティターン族の黄金時代
- レアーを妻とする
- しかし父と同じ運命を恐れる

## オリュンポスの神々の誕生

### クロノスの恐怖
- 「自分の子に倒される」という予言
- 生まれた子を次々と飲み込む

### 飲み込まれた子供たち
順に：
1. ヘスティアー（炉の女神）
2. デーメーテール（豊穣の女神）
3. ヘーラー（女王）
4. ハデス（冥界の王）
5. ポセイドーン（海神）

### ゼウスの救出

**レアーの策略**
- 6番目の子ゼウスを隠す
- クレタ島の洞窟で密かに育てる
- 石を布に包んでクロノスに飲ませる

**ゼウスの成長**
- アマルテイア（山羊）の乳で育つ
- クレタの精霊たちに守られる
- 戦いの準備を整える

## ティタノマキア（神々の戦争）

### 戦争の勃発

**ゼウスの帰還**
- 成長したゼウスが父に挑戦
- メティス（知恵の女神）が吐き薬を調合
- クロノスが子供たちを吐き出す
  - 順序：石 → ポセイドーン → ハデス → ヘーラー → デーメーテール → ヘスティアー

**陣営の分裂**
- **オリュンポス派**: ゼウス、ポセイドーン、ハデス、姉妹たち
- **ティターン派**: クロノス、多くのティターン族
- 中立：プロメテウス（後にゼウス側）、オーケアノス、テミス

### 10年戦争

**均衡状態**
- オリュンポス山 vs オトリュス山
- 10年間決着がつかない
- 世界が荒廃

**転機**
- ガイアの助言
- ゼウスがタルタロスからキュクロプスとヘカトンケイルを解放
- キュクロプスが武器を作る：
  - **ゼウス** → 雷電
  - **ポセイドーン** → 三叉の矛
  - **ハデス** → 隠れ兜

**最終決戦**
- ヘカトンケイルが山を投げつける
- ゼウスの雷電が炸裂
- ティターン族の敗北

### 戦後処理

**ティターン族の罰**
- タルタロスに幽閉
- ヘカトンケイルが番人
- 例外：
  - アトラス → 天空を永遠に支える罰
  - プロメテウス → 後に人類に火を与えて別の罰

**世界の分割**
- **ゼウス** → 天空と地上の支配権
- **ポセイドーン** → 海
- **ハデス** → 冥界
- ガイアは共有

## ギガントマキア（巨人族の戦い）

### ガイアの怒り
- 息子たち（ティターン）の敗北に憤慨
- ギガース（巨人族）を戦いに送る

### 予言
- 「神々だけでは巨人を倒せない。人間の英雄が必要」
- ゼウスがヘーラクレースを英雄として参戦させる

### 主な戦い
- **アルキュオネウス** vs ヘーラクレース
- **ポルピュリオーン** vs ゼウス＆ヘーラクレース
- **エンケラドス** vs アテーナー
- **ポリュボーテース** vs ポセイドーン

### 結果
- オリュンポスの神々の完全勝利
- 巨人族は埋葬される（火山はその怒り）

## テュポーンとの戦い

### 最後の脅威

**テュポーンの誕生**
- ガイアとタルタロスの子
- 最も恐ろしい怪物
- 上半身は人間、下半身は蛇
- 100の竜の頭
- 炎を吐く

**最終決戦**
- 神々は恐れて逃げる
- ゼウスだけが立ち向かう
- 壮絶な一騎打ち
- シチリア島に封印（エトナ火山）

### 秩序の確立
- すべての脅威を排除
- ゼウスの支配が確定
- オリュンポスの黄金時代の始まり

## 人類の創造

### プロメテウスの創造
- 粘土から人間を作る
- アテーナーが息を吹き込む
- 神々の姿に似せて作られる

### 5つの時代

1. **黄金時代**
   - クロノス統治下
   - 不死に近い幸福な人類
   - 労働不要

2. **銀の時代**
   - ゼウスの統治
   - 劣った人類
   - 神々を敬わず滅ぼされる

3. **青銅時代**
   - 好戦的な人類
   - 互いに殺し合い滅亡

4. **英雄時代**
   - 半神半人の英雄たち
   - トロイア戦争
   - 死後は至福の島へ

5. **鉄の時代（現代）**
   - 苦難の時代
   - 道徳の退廃
   - 労働と苦しみ

## プロメテウスの贈り物

### 火の窃盗
- 人類が寒さに苦しむ
- プロメテウスが天界から火を盗む
- フェンネルの茎に隠して持ち帰る

### ゼウスの怒り
- 人類への罰：パンドーラー
- プロメテウスへの罰：
  - カフカス山に鎖で繋がれる
  - 毎日鷲に肝臓を食われる
  - 夜には再生し、永遠の苦しみ
  - 後にヘーラクレースに救われる

## パンドーラーの箱

### 最初の女性
- ヘーパイストスが粘土から作る
- 各神が贈り物を与える：
  - アプロディーテー → 美
  - アテーナー → 技芸
  - ヘルメース → 嘘と好奇心

### 箱（実は壺）
- 「決して開けるな」と警告される
- 好奇心に負けて開ける
- すべての災い（病気、苦しみ、死）が世界に放たれる
- 底に残ったのは「希望」のみ

## 大洪水神話

### デウカリオーンの洪水

**原因**
- 青銅時代の人間の邪悪さ
- ゼウスが人類を滅ぼすことを決意

**生存者**
- デウカリオーン（プロメテウスの息子）
- ピュラー（エピメテウスとパンドーラーの娘）
- 9日9晩の大雨
- 箱船で生き延びる

**再創造**
- パルナッソス山に漂着
- テミスの神託：「母の骨を投げよ」
- 「母」= ガイア（大地）、「骨」= 石
- 投げた石が新しい人類になる
  - デウカリオーンの石 → 男性
  - ピュラーの石 → 女性

## 創世神話の教訓

1. **秩序への進化**: 混沌から秩序へ
2. **世代交代**: 古い世代が新しい世代に倒される運命
3. **傲慢への警告**: 神々も人間も、傲慢は破滅を招く
4. **希望の重要性**: どんな苦難にも希望は残る
5. **犠牲の意味**: プロメテウスの人類愛

この創世神話は、ギリシャ人の世界観と価値観の基盤となっています。
