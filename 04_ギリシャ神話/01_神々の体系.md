# オリュンポス十二神と主要な神々

ギリシャ神話の神々は、オリュンポス山に住むとされる十二神を中心に、人間的な感情と性格を持つ存在として描かれています。

## オリュンポス十二神

### ゼウス - 最高神
- **役割**: 神々と人間の王、雷と天空の神
- **シンボル**: 雷電、鷲、樫の木
- **特徴**: 全知全能だが女好き、多くの子供を持つ
- **ローマ名**: ユピテル（Jupiter）

### ヘーラー - 女王
- **役割**: 結婚と女性の守護神
- **シンボル**: 孔雀、牛、ざくろ
- **特徴**: ゼウスの正妻、嫉妬深く、夫の愛人や子を迫害
- **ローマ名**: ユーノー（Juno）

### ポセイドーン - 海の支配者
- **役割**: 海、地震、馬の神
- **シンボル**: 三叉の矛（トライデント）
- **特徴**: ゼウスの兄弟、気性が荒い
- **ローマ名**: ネプトゥーヌス（Neptune）

### デーメーテール - 豊穣の女神
- **役割**: 農業、豊穣、季節の神
- **シンボル**: 麦の穂、松明
- **神話**: 娘ペルセポネの誘拐と四季の起源
- **ローマ名**: ケレース（Ceres）

### アテーナー - 知恵の女神
- **役割**: 知恵、戦略、工芸の神
- **誕生**: ゼウスの頭から完全武装して誕生
- **シンボル**: 梟、オリーブ、盾（アイギス）
- **特徴**: 処女神、アテネの守護神
- **ローマ名**: ミネルウァ（Minerva）

### アポローン - 光明神
- **役割**: 太陽、音楽、予言、医療、弓術の神
- **シンボル**: 竪琴、月桂樹、弓
- **神託所**: デルポイ
- **特徴**: 美しい青年神、芸術のパトロン
- **ローマ名**: アポロ（Apollo）

### アルテミス - 月と狩猟の女神
- **役割**: 月、狩猟、純潔、出産の神
- **シンボル**: 弓、鹿、三日月
- **特徴**: アポローンの双子の姉妹、処女神
- **ローマ名**: ディアーナ（Diana）

### アプロディーテー - 美の女神
- **役割**: 愛、美、性愛の神
- **誕生**: 海の泡から生まれる
- **シンボル**: 鳩、薔薇、貝殻
- **特徴**: 絶世の美女、ヘーパイストスの妻だがアレースと不倫
- **ローマ名**: ウェヌス（Venus）

### アレース - 戦争神
- **役割**: 戦争、戦闘、暴力の神
- **シンボル**: 槍、盾、犬、禿鷹
- **特徴**: 残忍で血に飢えた戦士、あまり人気がない
- **ローマ名**: マールス（Mars）

### ヘーパイストス - 鍛冶神
- **役割**: 鍛冶、工芸、火の神
- **シンボル**: 金槌、炉、斧
- **特徴**: 神々の中で唯一醜い、足が不自由、神々の武器を作る
- **ローマ名**: ウゥルカーヌス（Vulcan）

### ヘルメース - 伝令神
- **役割**: 伝令、商業、旅、盗賊の神
- **シンボル**: 翼のついたサンダルと帽子、ケーリュケイオン（杖）
- **特徴**: 機知に富み、雄弁、死者を冥界に導く
- **ローマ名**: メルクリウス（Mercury）

### ディオニューソス - 酒神
- **役割**: 酒、演劇、陶酔、豊穣の神
- **シンボル**: 葡萄、蔦、テュルソス（杖）
- **特徴**: 後から十二神に加わる、祭祀と演劇の起源
- **ローマ名**: バックス（Bacchus）

*注: ヘスティアー（炉の女神）が十二神に含まれる版もあり、その場合はディオニューソスと入れ替わります。*

## その他の重要な神々

### ハデス - 冥界の王
- **役割**: 冥界と死者の支配者
- **シンボル**: 冥界の兜（透明になれる）、二股の槍
- **特徴**: ゼウスの兄弟、冥界から出ることは少ない、十二神には数えられない

### ヘスティアー - 炉の女神
- **役割**: 家庭の炉、家族の絆の神
- **特徴**: 処女神、最も古い神の一人、地味だが重要

### ペルセポネ - 冥界の女王
- **役割**: 冥界の女王、春の女神
- **神話**: ハデスに誘拐され、1年の半分を冥界で過ごす（四季の起源）

### パン - 牧神
- **姿**: 山羊の下半身、角を持つ
- **役割**: 羊飼い、森、野生の神
- **特徴**: パニック（panic）の語源

### エロース - 愛の神
- **役割**: 恋愛感情を引き起こす
- **シンボル**: 弓と矢
- **特徴**: アプロディーテーの息子（または原初の神）

## 原初の神々

### カオス - 混沌
最初に存在した虚空

### ガイア - 大地
自ら存在した大地の女神、多くの神々の母

### ウーラノス - 天空
ガイアの息子にして夫、ティターン族の父

### クロノス - 時間
ティターン族の王、ゼウスの父

## 神々の特徴

1. **人間的**: 感情、欲望、過ちを持つ
2. **不死**: 死なないが傷つくことはある
3. **変身**: 様々な姿に変身できる
4. **不完全**: 完璧ではなく、争いや嫉妬もある
5. **家族関係**: 複雑な親族関係と恋愛関係
