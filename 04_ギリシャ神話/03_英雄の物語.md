# ギリシャ神話の英雄たち

ギリシャ神話の英雄は、神と人間の間に生まれた半神半人、または優れた能力を持つ人間です。彼らの冒険譚は、勇気、知恵、運命との戦いを描いています。

## ペルセウス - メドゥーサ退治

### 誕生の物語 - 避けられない運命

**アルゴス王アクリシオスの恐怖**
- 王子が生まれず、娘ダナエーのみ
- 神託に尋ねる：「私に王子は生まれますか？」
- 神託の答え：
  - 「王子は生まれない」
  - 「しかし娘が孫を産む」
  - 「その孫がお前を殺す」

**娘の幽閉**
- アクリシオス王、恐怖に駆られる
- ダナエーを聖堂の塔に幽閉
- 鉄格子で完全に密閉
- 「子を産むな」

**ゼウスの訪問 - 黄金の雨**
- ゼウス、塔に閉じ込められた美女ダナエーを見つける
- 鉄格子も壁も関係ない
- **黄金の雨**に変身して侵入
- ダナエー「何？綺麗...あぁ、ゼウス様！？」
- ゼウス「分からなかったか？」

**母子の追放**
- ダナエー、妊娠
- アクリシオス王「お腹大きくない？」
- ダナエー「色々あって...」
- 王、孫を殺すことはできず
- **木の箱に母子を入れて海に流す**
- ダナエー「何これ？流されてるんですけど」

**セリポス島への漂着**
- 小さな島に流れ着く
- 漁師に救われる
- ペルセウスと名付けた息子と慎ましく暮らす

### セリポス島での苦難

**島の権力者ポリュデクテスの執着**
- 美女ダナエーが島に流れ着いた噂が広まる
- セリポス島の王ポリュデクテス、ダナエーを狙う
- しつこく求婚するが断られ続ける
- ダナエー「私はペルセウスを育てるのに手一杯」
- ペルセウス成長「母さんは俺が守る」

**ポリュデクテスの陰謀**
- 邪魔なペルセウスを追い出す計画
- 嘘の結婚パーティーを開催
- 「祝いとして馬を献上せよ」
- 貧しいペルセウスには馬がない
- ペルセウス「馬の代わりに何でも出します」
- ポリュデクテス「ではゴルゴン3姉妹を退治し、その首を持ってこい」
  - 事実上の死刑宣告

### メドゥーサ退治 - 神々の全面支援

**ゼウスの決断**
- 息子ペルセウスの窮地を見ている
- 「私の息子を助けろ」
- アテーナーとヘルメースを派遣

**最強装備の授与**
アテーナーとヘルメース、ペルセウスの前に現れる：

1. **金剛の鎌**（ダイヤモンド製）
   - 絶対に傷つかない

2. **青銅の盾**（アテーナーの私物）
   - 鏡のように磨かれている
   - アテーナー「これ、私が普段使ってるものです」
   - ペルセウス「直で？いいんですか？」

3. **隠れ兜**（ハーデースの私物）
   - 姿が完全に消える
   - ペルセウス「ハーデース様のを？すごい」

4. **空飛ぶサンダル**（ヘルメースの私物）
   - ヘルメース「私からも差し上げます」
   - 空を自由に飛べる

**フルサポート体制**
- ヘルメース「案内は僕がします」
- アテーナー「作戦は私が立てます」
- ペルセウス「フルナビゲーション!?　レベル99装備じゃないですか」
- ヘルメース「これ会長直々の案件ですから」

**メドゥーサ退治の戦略**

ヘルメース飛びながら説明：
- 「ゴルゴン3姉妹のうち2人は不死身です」
- 「メドゥーサだけが不死身じゃない」
- 「そこを狙います」

アテーナーの作戦：
- 「直接目を見たら石になります」
- 「でも鏡越しなら大丈夫」
- 「盾を鏡として使ってください」

**完璧な暗殺**
- 姿を消して（隠れ兜）
- 空を飛んで（サンダル）
- 盾の反射でメドゥーサの位置確認
- 眠っている間に
- 一撃で首を切断（金剛の鎌）
- 袋に首を入れて即座に飛び去る

ゴルゴン姉妹「メドゥーサ？どこ？」
→ もう遅い

**メドゥーサの血から**
- 天馬ペガソス誕生
- 巨人クリュサオール誕生

### アンドロメダーの救出 - 運命の出会い

**カッシオペイア王妃の傲慢**
エチオピア王国にて：
- カッシオペイア「私の娘アンドロメダーは海の精霊（ネーレーイデス）より美しい」
- 海の精霊たち「なんですって？人間ごときが！」
- ポセイドーンに訴える

**ポセイドーンの激怒**
- 「俺の娘たち（海の精霊）を侮辱するのか？」
- 海の怪物ケートスを差し向ける
- 国中が荒らされる
- 神託「王女を生贄に捧げよ」

**生贄の儀式**
- 断崖絶壁の岩にアンドロメダーを鎖で縛る
- カッシオペイア「ごめんなさい...でも国のために」
- アンドロメダー「お母様...仕方ないわ」
- 海から巨大な怪物が近づいてくる

**ペルセウスの登場**
- 空飛ぶサンダルで飛行中、美しい少女を発見
- ペルセウス「なぜあんな美しい人が？」
- 急降下して確認
- 一目惚れ「絶対に助ける！」

**交渉**
- 王のもとへ
- ペルセウス「娘さんを僕にください。怪物は倒します」
- 王「本当に倒せるのか？」
- ペルセウス（メドゥーサの首を見せる）「これで倒したんです」
- 王「わかった！約束する！」

**怪物退治**
- 海から巨大なケートスが現れる
- 空飛ぶサンダルで空中戦
- 「見ろ！」メドゥーサの首を見せる
- ケートス、一瞬で石化
- ドーン！海に沈む

**結婚式の襲撃**
- 元婚約者ピーネウスが兵を率いて乱入
- ピーネウス「アンドロメダーは俺のものだ！」
- 大乱闘開始
- ペルセウス、メドゥーサの首を掲げる
- ピーネウスと兵士たち全員石化

**星座の誕生**
- ペルセウス座
- アンドロメダ座
- カッシオペイア座（W字型 - 永遠に逆さ吊りの罰）

星座豆知識：
- 「カシオペア座とアンドロメダ座が見えたら、近くにペルセウス座がありますよ」
- 「なんで？」
- 「恋人ですから」

### 帰還と予言の成就

**セリポス島への帰還**
- ポリュデクテス王「まさか生きて戻るとは」
- ペルセウス「母を返してください」
- 王「お前の母は俺のものだ」
- ペルセウス、メドゥーサの首を見せる
- 王と取り巻き全員石化

**アルゴスでの悲劇**
- 祖父アクリシオス、孫の生存を知り恐怖で逃亡
- ペルセウス、円盤投げ競技に参加
- 投げた円盤が観客席に
- 観客の中にいた祖父に命中
- アクリシオス死亡

**予言の成就**
- ペルセウス「円盤投げには...ご注意を」（後世への警告）
- 避けようとしても避けられない運命
- ギリシャ悲劇の本質を体現

## ヘーラクレース - 強すぎた男

### 誕生と幼少期 - ヘーラーの憎悪

**ゼウスの不倫**
- アルクメネー（ペルセウスの孫）
- 夫に化けて近づく
- アルクメネー「あれ？もうお帰り？」
- ゼウス「今日は仕事休んで...愛し合わないか？」
- 行為後、正体を明かす
- アルクメネー「最低じゃないですか！夫になりすますなんて！」
- ゼウス「最低かどうかは後世の人が決めます」（即座に逃走）

**双子の妊娠**
- 夫との子イピクレースとゼウスとの子ヘーラクレースを双子妊娠
- ゼウス「次に生まれる子がミュケナイの王になる！」
- ヘーラー「何世代にも渡って浮気しとんねん！」
- 出産を遅らせてイピクレースを先に王にする

**赤子への刺客**
- ヘーラー「赤ん坊のうちに殺したらええねん」
- 生後数ヶ月のヘーラクレースに2匹の大蛇を送る
- 家族「ぎゃー！大蛇が！」
- シャー（蛇の襲撃）
- 赤ん坊ヘーラクレース、両手で蛇を掴む
- ブチッ！グシャ！
- 蛇を絞め殺す
- ヘーラクレース「ばーぶー」（そのまま寝る）
- 家族「こいつはとんでもない男になる！」

**伝説の始まり**
- 優秀な教育係をつける
- 武芸、知恵、全てに秀でる
- ただし短気な性格

**琴の教師殺害事件**
- 琴の授業でうまくできない
- 教師「ダメだろヘーラクレス！」（ペン）
- ヘーラクレース「何すんですか！」
- 琴を投げ返す
- 教師、即死
- ヘーラクレース「強すぎるのも罪...」

**ヘーラーの呪い**
- 成長し、妻子を得る
- ヘーラー「順調に育っちゃってるじゃない」
- 呪いで発狂させる
- ヘーラクレース「うわー！止まらない！」
- 我が子を殺してしまう
- ヘーラクレース「俺の力が...こんなことに」

**アポロンの神殿**
- ボロボロのヘーラクレース、神託を求める
- アポロン「12の試練を超えよ」
- 「ミュケナイの王イピクレースに仕えよ」
- 「それで自由になれる」

**イピクレースの恐怖**
- 臆病な王イピクレース
- 「なんだ？あの強くて恐ろしいヘーラクレースが来た！」
- 「王座を狙っているに違いない！」
- 「無理難題を押し付けて殺してやる」

### 12の功業 - 長編RPGの始まり

**任務**

**戦利品**
- ライオンの爪で毛皮を剥ぐ

**イピクレースの反応**

#### 2. レールナイアーのヒュドラー - 毒矢の誕生

**任務**

**第一次戦闘**
- スパーン！（首を切る）
- うにゅうにゅ...再生する
- しかも二股に分かれる
- ヘーラクレース「何この設定！やばすぎる！」
- 一旦撤退

**作戦会議**
- 甥のイオラオスと相談
- イオラオス「断面を焼けば？」
- ヘーラクレース「天才か！」

**第二次戦闘**
- ズバー！（首を切る）
- イオラオス、松明で断面を焼く
- 「おじちゃん、焼いてるで！」
- ジュー！再生しない
- 「おおー！いけるね！」
- スパンスパンジュージュー
- 最後の不死の首だけ残る

**封印**
- 「この首は不死だから...」
- 穴を掘る
- 不死の首をガー！（穴に押し込む）
- 大岩を持ってきて封印

**ヒュドラの毒矢**
- ヒュドラの体からビチビチ毒が
- 「この毒...何かに使えないかな？」
- 慎重に毒を採取
- 矢尻に塗る
- **ヒュドラの毒矢**完成
- 一撃で肌が腐って死ぬ最強の武器

**イピクレースの反応**
- 「ヒュドラくらいやばいやつじゃないと...」
- ドン！「帰りました」
- 「嘘でしょ？」
- 青銅の壺を用意
- イピクレース、面会時は壺の中に隠れるようになる
