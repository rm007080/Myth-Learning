# 天岩戸と高天原の神話

天岩戸（あまのいわと）神話は、太陽神である天照大御神が岩戸に隠れ、世界が暗黒に包まれる物語です。日本神話で最も有名な神話の一つであり、神楽や祭礼の起源とされています。

## 黄泉国訪問（前段）

天岩戸神話の前提となる重要な出来事。

### 伊邪那岐の黄泉国訪問

**動機**
- 妻イザナミの死を嘆く
- 「一目会いたい」
- 黄泉国（死者の国）へ向かう

**黄泉国での再会**

伊邪那美との対話：
- イザナギ「一緒に帰ろう」
- イザナミ「もう黄泉の食べ物を食べてしまった。でも黄泉神に相談してみる。**決して覗かないで**」

**禁忌の破り**
- 待ちきれずに覗いてしまう
- 火を灯して見ると
- 腐敗した妻の姿
- 体に雷神と黄泉醜女（ヨモツシコメ）が群がる

**追跡と逃走**
- イザナミ「私に恥をかかせた！」
- 黄泉醜女を差し向ける
- イザナキは髪飾りや櫛を投げて逃げる
  - 髪飾り→葡萄に変化
  - 櫛→筍に変化
- 追手が食べている間に逃げる

**最後の対峙**

**千引石（ちびきのいわ）**
- 黄泉比良坂（ヨモツヒラサカ）の境界
- 大岩で塞ぐ
- イザナミと完全に別れる

**呪いと誓い**
- イザナミ「あなたの国の人を1日千人殺す」
- イザナギ「ならば私は1日千五百人生ませよう」
- **生と死の起源**
- 人口が増える理由

## 禊と三貴子の誕生

**場所**

黄泉の穢れを祓うため：

**衣服を脱ぐ**

**上流の瀬で禊**

**下流の瀬で禊**
- 流れが弱すぎる

**中流の瀬で禊**
- ちょうどよい

- **役割**: 夜之食国（よるのおすくに）を治めよ

#### 建速須佐之男命（タケハヤスサノオノミコト）
- **誕生**: 鼻を洗って誕生
- **役割**: 海原を治めよ
- **性質**: 嵐神、破壊と創造

## 高天原でのスサノオの乱暴

### 疑われる訪問

**アマテラスの警戒**
- スサノオが高天原に昇ってくる
- 山川が震動、大地が揺れる
- 「国を奪いに来たのでは？」
- 武装して待ち構える

**誓約（うけひ）による証明**

互いの持ち物から神を生む競争：

**スサノオの剣からアマテラスが生んだ神**
1. 多紀理毘売命（タギリビメ）
2. 市寸島比売命（イチキシマヒメ）
3. 多岐都比売命（タギツヒメ）
- 三女神（宗像三女神）

**アマテラスの勾玉からスサノオが生んだ神**
1. 正勝吾勝勝速日天之忍穂耳命（マサカツアカツカチハヤヒアメノオシホミミ）
2. 天之菩卑能命（アメノホヒ）
3. 天津日子根命（アマツヒコネ）
4. 活津日子根命（イクツヒコネ）
5. 熊野久須毘命（クマノクスビ）
- 五男神

**結論**
- 「私の心が清いから優しい女神が生まれた」
- スサノオの勝利を宣言
- アマテラスは認める

### 勝ちに乗じた乱暴

**農業妨害**
- 田の畔を壊す
- 溝を埋める

**穢し行為**
- 新嘗祭（にいなめさい）の御殿に糞をする

**最悪の行為**
- 天の服織女（はたおりめ）が機を織っている
- 屋根に穴を開ける
- 斑馬（まだらうま）の皮を剥いで投げ込む
- 驚いた織女が梭（ひ）で陰部を突いて死ぬ

## 神々の会議と作戦

### 八百万神の集会

**場所**
- 天の安の河原（あめのやすのかわら）

**主導者**
- 高御産巣日神（タカミムスビ）
- 思金神（オモイカネ）- 知恵の神が作戦立案

### 作戦の実行

#### 1. 鏡の製作
**職人**: 伊斯許理度売命（イシコリドメ）と天津麻羅（アマツマラ）
- **八咫鏡**（やたのかがみ）を作る
- 三種の神器の一つ

#### 2. 勾玉の製作
**職人**: 玉祖命（タマノオヤ）
- **八尺瓊勾玉**（やさかにのまがたま）を作る
- 三種の神器の一つ

#### 3. 榊の木の準備
**天の香具山の榊**
- 上枝：八尺瓊勾玉
- 中枝：八咫鏡
- 下枝：青和幣（あおにぎて）と白和幣（しろにぎて）

#### 4. 祝詞の準備
**天児屋命**（アメノコヤネ）と**布刀玉命**（フトダマ）
- 祝詞を奏上
- 榊を捧げ持つ

#### 5. 力持ちの配置
**天手力男神**（アメノタヂカラオ）
- 岩戸の脇に隠れて待機
- 扉を開ける役

#### 6. 天宇受売命の舞

**最重要の役割**

**準備**
- 天の香具山の日陰蔓（ひかげかずら）を襷に
- 笹の葉を手に持つ
- 伏せた桶の上に立つ

**神懸かり**
- トランス状態になる
- 乳房を露わにする
- 裳の紐を陰部まで押し下げる

**踊り**
- 激しく踊る
- 足踏み鳴らす
- 桶が鳴り響く

**効果**
- 高天原が震動するほど
- 八百万の神々が一斉に笑う

## 神話の意義とテーマ

### 太陽の復活

**自然現象の神話化**
- 日食？
- 冬至から春分への太陽の復活？
- 太陽崇拝の表現

### 祭祀の起源

**神楽の起源**
- アメノウズメの舞 = 神楽舞の原型
- 笑いと騒ぎ = 祭りの本質
- 神を喜ばせる

**新嘗祭の起源**
- 収穫祭の重要性
- スサノオの妨害行為が逆説的に重要性を示す

### 兄妹の対比

**アマテラス**
- 責任感が強い
- 秩序の象徴
- しかし傷つきやすい

**スサノオ**
- 感情的
- 混沌の象徴
- しかし純粋な心
- 後に英雄となる

### 光と闇

**光の神聖性**
- 太陽がなければ世界は滅びる
- 光 = 秩序、善
- 闇 = 混沌、悪

### 神々の協力

**集合知**
- 一神では解決できない
- 八百万の神の協力
- それぞれの得意分野

### 笑いの力

**笑いによる呪術**
- 悪を追い払う
- 神を喜ばせる
- 祝祭の力
