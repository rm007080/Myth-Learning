# 世界神話大全 - 初学者のための総合教材

## ようこそ

このリポジトリは、世界の主要な神話体系を初学者向けに体系的にまとめた教科書的資料です。人類が何千年もかけて紡いできた物語、信仰、世界観を、起源の古い順に学ぶことができます。

## 📚 収録している神話

神話の起源順に以下の6つの神話体系を詳しく解説しています：

### 1. [メソポタミア神話](./01_メソポタミア神話/)
**紀元前3000年頃〜**
- 世界最古の文明から生まれた神話
- ギルガメシュ叙事詩、エヌマ・エリシュ（創世神話）
- 旧約聖書への多大な影響
- チグリス・ユーフラテス川流域（現イラク）

### 2. [エジプト神話](./02_エジプト神話/)
**紀元前3000年頃〜**
- ナイル川流域で3000年続いた神話体系
- オシリス神話、ラーの太陽の旅
- 来世と死後の世界への深い関心
- ピラミッド、ミイラ文化の背景

### 3. [インド神話](./03_インド神話/)
**紀元前1500年頃〜（ヴェーダ時代）**
- 現在も生きている神話伝統
- ヴェーダ、マハーバーラタ、ラーマーヤナ
- トリムルティ：ブラフマー、ヴィシュヌ、シヴァ
- 驚異的なスケールと哲学的深さ
- ヒンドゥー教の基盤

### 4. [ギリシャ神話](./04_ギリシャ神話/)
**紀元前800年頃〜**
- 西洋文明の文化的基盤
- オリュンポスの十二神、英雄たちの冒険
- ホメロス、ヘシオドスによる記録
- 芸術、文学、哲学への計り知れない影響
- ローマ神話として継承

### 5. [北欧神話](./05_北欧神話/)
**紀元後800-1000年頃（ヴァイキング時代）**
- スカンディナヴィアのヴァイキングの神話
- オーディン、トール、ロキ
- ユグドラシル（世界樹）と九つの世界
- ラグナロク（神々の黄昏）
- 現代ファンタジーへの多大な影響

### 6. [日本神話（古事記）](./06_日本神話（古事記）/)
**712年（古事記編纂）**
- 日本列島の神話と伝説
- 国生み、天岩戸、ヤマタノオロチ
- 天照大御神、須佐之男命、大国主神
- 天皇家の起源神話
- 神道の基盤、現代日本文化の源流

## 📖 学習の進め方

### 初めての方へ

#### ステップ1：興味のある神話から始める
最初は一番興味を持った神話体系から読み始めてください。どれから始めても問題ありません。

#### ステップ2：各神話のREADMEを読む
各フォルダの `README.md` で全体像を把握しましょう。

#### ステップ3：詳細な資料を読む
興味を持った部分から、詳細な資料（01_神々の体系.md など）を読み進めます。

#### ステップ4：比較してみる
複数の神話を学んだら、共通点と相違点を比較してみましょう。

### 体系的に学びたい方へ

#### 推奨順序：起源の古い順
1. メソポタミア神話 → 人類最古の文明の神話
2. エジプト神話 → 古代文明の死生観
3. インド神話 → 哲学的な深さと壮大さ
4. ギリシャ神話 → 西洋文明の基盤
5. 北欧神話 → ヴァイキングの世界観
6. 日本神話 → 日本文化の源流

この順序で学ぶことで、神話の発展と文化的伝播を理解できます。

### 文化的伝播の流れ

```
メソポタミア → エジプト（交易）
    ↓
ギリシャ ← カナン/フェニキア
    ↓
ローマ → ヨーロッパ全域

メソポタミア → ペルシャ → インド
         ↓
      旧約聖書 → キリスト教・イスラム教

インド → 東南アジア → 中国 → 日本（仏教経由）
```

## 🎓 学習のためのヒント

### 神話を理解するポイント

1. **歴史的背景を知る**
   - その時代の人々の生活
   - 自然環境と気候
   - 政治体制と社会構造

2. **象徴を読み解く**
   - 神々は何を象徴しているか
   - 物語が伝えたいメッセージは何か
   - なぜこの物語が必要だったのか

3. **比較することで深まる理解**
   - 他の神話との共通点
   - 独自の特徴は何か
   - 文化的背景の違い

4. **現代との繋がりを意識する**
   - 現代文化への影響
   - 普遍的なテーマ
   - 現代に生きる私たちへのメッセージ

### 推奨される読み方

- **1回目**: 物語として楽しむ
- **2回目**: 神々の関係性や象徴を考える
- **3回目**: 歴史的・文化的背景と照らし合わせる
- **4回目**: 他の神話と比較する

## 🌟 神話を学ぶ意義

### 1. 人類の知恵の結晶
神話は、古代の人々が世界を理解し、意味を見出そうとした試みです。そこには普遍的な人間の問いと答えがあります。

### 2. 文化理解の基盤
現代文化の多くは神話に根ざしています。神話を知ることで、文学、芸術、思想をより深く理解できます。

### 3. 想像力の源泉
神話は無限の想像力と創造性の宝庫です。現代の創作活動のインスピレーションとなり続けています。

### 4. 自己理解への道
神話の英雄たちの旅は、私たち自身の人生の旅と重なります。試練、成長、そして帰還というパターンは、人生そのものの比喩です。

### 5. 異文化理解
異なる文化圏の神話を学ぶことで、多様な世界観と価値観を理解し、寛容性を育むことができます。
