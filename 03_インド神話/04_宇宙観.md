# インド神話の宇宙観

インド神話の宇宙観は、その驚異的なスケールと哲学的深さで知られています。

## 時間の概念

### ユガ（時代）のサイクル

4つのユガが1つのマハー・ユガ（大周期）を形成：

1. **クリタ・ユガ**（サティヤ・ユガ）- 黄金時代
   - 期間: 1,728,000年
   - 特徴: 完璧な徳、長寿、病気なし
   - ダルマは4本足で立つ（完全）

2. **トレーター・ユガ** - 銀の時代
   - 期間: 1,296,000年
   - 特徴: 徳が少し減少、儀式の始まり
   - ダルマは3本足

3. **ドヴァーパラ・ユガ** - 銅の時代
   - 期間: 864,000年
   - 特徴: 徳と悪が半々、病気の出現
   - ダルマは2本足

4. **カリ・ユガ** - 鉄の時代（現在）
   - 期間: 432,000年
   - 開始: 紀元前3102年（クリシュナの死）
   - 特徴: 徳の衰退、戦争、不和、短命
   - ダルマは1本足のみ
   - カルキ（ヴィシュヌの第10化身）が終わりに出現

### より大きな時間単位

**マハー・ユガ**（大周期）:
- 4つのユガの合計 = 4,320,000年

**カルパ**（ブラフマーの1日）:
- 1,000マハー・ユガ = 43億2000万年
- ブラフマーの1日は14のマヌの時代を含む

**ブラフマーの寿命**:
- 100ブラフマー年 = 311兆400億年
- 現在は51ブラフマー年目

### 夜と昼の創造

- **ブラフマーの昼**: 宇宙が存在（43億年）
- **ブラフマーの夜**: 宇宙が休眠（43億年）
- 永遠に繰り返される

## 空間の概念

### 三界（トリローカ）

1. **スヴァルガ**（天界）
   - 神々が住む
   - インドラが支配
   - 善行の報酬として一時的に滞在

2. **マルティヤローカ**（中間界・地上）
   - 人間が住む
   - 修行の場

3. **パーターラ**（地下界）
   - 7つの層
   - ナーガ（蛇神）などが住む
   - 必ずしも悪い場所ではない

### 宇宙の卵（ブラフマーンダ）

宇宙は巨大な卵として描かれます：
- 外殻: 7つの層（地、水、火、風、空、マハット、アヴィヤクタ）
- 内部: 無数の世界

### 宇宙を支えるもの

**世界亀と蛇**:
- 大地は4頭の象に支えられる
- 象は世界亀クールマの甲羅に立つ
- 亀は宇宙の蛇シェーシャの上に乗る
- シェーシャは宇宙の海に浮かぶ

**ヴィシュヌ**:
- 乳の海に横たわり、蛇シェーシャの上で休む
- へそから蓮が伸び、ブラフマーが生まれる

## 創造と破壊のサイクル

### 創造（スリシュティ）

**ブラフマーによる創造**:
1. ブラフマーが瞑想する
2. 原初の音「オーム」が響く
3. マハット（宇宙知性）が生まれる
4. アハムカーラ（自我）が生まれる
5. 5つの元素が顕現
6. 生命が創造される

**段階的創造**:
- まず神々
- 次にアスラ（悪魔）
- そして人間
- 動物と植物

### 維持（ステティ）

**ヴィシュヌの役割**:
- 宇宙の秩序（リタ）を維持
- 危機の時に化身として降臨
- マーヤー（幻影）で世界を維持

### 破壊（サムハーラ）

**シヴァによる破壊**:
- カルパの終わりに宇宙を破壊
- タンダヴァ（破壊の舞踊）
- 火で全てを焼き尽くす
- 破壊は再生のため

### プララヤ（宇宙の溶解）

ブラフマーの夜の間：
- すべてが原初の水（ナーラーヤナ）に溶け込む
- 神々も休眠
- ブラフマーの昼が来ると再創造

## 輪廻転生（サンサーラ）

### 魂（アートマン）の旅

1. **誕生**: カルマに応じて生まれる
2. **生**: 行為（カルマ）を積む
3. **死**: 身体を離れる
4. **中間状態**: ヤマ（死の神）の裁き
5. **再生**: 新しい身体に入る

### 生まれ変わりの可能性

**上方への転生**:
- 神々（デーヴァ）
- 人間
- 動物
- 植物

**下方への転生**:
- 餓鬼（プレータ）
- 地獄の住人

### カルマの法則

- **善いカルマ**: より良い生へ
- **悪いカルマ**: より悪い生へ
- **混合カルマ**: 混合した結果
- **無執着の行為**: カルマを作らない

### 解脱（モクシャ）

輪廻からの解放：
- **ジュニャーナ**（知識）の道
- **バクティ**（献身）の道
- **カルマ**（無執着の行為）の道
- **ラージャ・ヨーガ**（瞑想）の道

解脱を達成すると：
- 輪廻から解放
- ブラフマン（宇宙の根本原理）と合一
- または神の領域で永遠に過ごす

## 哲学的概念

### ブラフマン

- 究極の実在
- 無形、無限、永遠
- 全てはブラフマンの顕現

### アートマン

- 個我、真の自己
- 不滅、永遠

### マーヤー

- 幻影、神の創造力
- 多様性を生み出す
- 真実（ブラフマン）を覆い隠す

### リタ

- 宇宙の秩序
- 自然法則
- ダルマの基盤

## 宇宙の終末

### プララヤ（溶解）の種類

1. **ニトヤ・プララヤ**（日常的溶解）
   - 個々の生命の死

2. **ナイミッティカ・プララヤ**（偶然的溶解）
   - カルパの終わり（ブラフマーの1日）
   - シヴァの破壊の舞踊

3. **プラークリタ・プララヤ**（自然的溶解）
   - ブラフマーの寿命の終わり
   - 完全な溶解

4. **アーテャンティカ・プララヤ**（最終的溶解）
   - 個人の解脱
   - 輪廻からの解放

## 現代科学との対話

### 興味深い一致

- **膨張と収縮**: ビッグバンとビッグクランチ
- **時間のスケール**: 数十億年単位
- **周期的宇宙**: 永遠の創造と破壊
- **多元宇宙**: 無数の世界（ローカ）

### 違い

- 科学: 物理法則による
- 神話: 神々の意志による
- 科学: 観測可能
- 神話: 信仰と体験

## まとめ

インド神話の宇宙観は：

1. **壮大なスケール**: 数兆年、無限の空間
2. **周期性**: 永遠の創造と破壊
3. **多層構造**: 14の世界、無数の生命形態
4. **道徳的宇宙**: カルマの法則が支配
5. **解脱の可能性**: 輪廻からの解放
6. **統一性**: 全てはブラフマンの顕現

この宇宙観は、人間の行為に意味を与え（カルマ）、同時に永遠の視点を提供します（解脱）。時間と空間の驚異的なスケールは、人間の小ささと同時に、魂の不滅性を教えています。
