# 北欧神話

## 概要

北欧神話（ノルド神話）は、スカンディナヴィア地域（現在のノルウェー、スウェーデン、デンマーク、アイスランド）で発展した神話体系です。ヴァイキング時代（8-11世紀）に最も盛んでした。

## 時代背景

- **ヴァイキング時代** (793-1066年): 北欧神話の最盛期
- **キリスト教化** (10-12世紀): 徐々にキリスト教へ改宗
- **記録期** (13世紀): アイスランドで文字記録
- **近代の再発見** (19世紀〜): ロマン主義運動での再評価

## 主要文献

### エッダ
#### 古エッダ（詩のエッダ）
- 9-13世紀の詩の集成
- 『巫女の予言』: 創世とラグナロクを語る
- 『ハーヴァマール』: オーディンの智慧の言葉
- 様々な神話と英雄の歌

#### 新エッダ（散文のエッダ）
- スノッリ・ストゥルルソン著(1220年頃)
- 神話の体系的な解説
- 『ギュルヴィたぶらかし』: 主要な神話物語
- 詩作法の教科書としても機能

### サガ
- **『ヴォルスンガ・サガ』**: 英雄ジークフリートの物語
- **『ヘルヴォルとヘイズレク王のサガ』**: 魔剣の物語
- **『ラグナル・ロズブロークのサガ』**: 伝説的ヴァイキング王

## 世界観

### ユグドラシル（世界樹）
宇宙を支える巨大なトネリコの木：
- 三本の根が三つの世界に伸びる
- ラタトスク（リス）が上下を往復
- ニーズヘッグ（竜）が根を齧る
- 四頭の鹿が枝葉を食べる

### 九つの世界

| 世界 | 住人 | 特徴 |
|------|------|------|
| **アースガルズ** | アース神族 | 神々の世界、ヴァルハラ |
| **ミズガルズ** | 人間 | 中つ国、人間界 |
| **ヨトゥンヘイム** | 巨人 | 巨人の国 |
| **ヴァナヘイム** | ヴァン神族 | 豊穣の神々の世界 |
| **アールヴヘイム** | 光の妖精 | 妖精の世界 |
| **スヴァルトアールヴヘイム** | 闇の妖精/ドワーフ | 地下世界 |
| **ニヴルヘイム** | - | 霧と氷の世界 |
| **ムスペルヘイム** | 炎の巨人 | 炎の世界 |
| **ヘルヘイム** | 死者 | 冥界 |

## 主要な神々

### アース神族

#### オーディン (Odin)
- **役割**: 最高神、戦争、知恵、詩、魔術
- **シンボル**: グングニル（槍）、スレイプニル（八本脚の馬）、フギンとムニン（二羽のワタリガラス）
- **特徴**:
  - 片目を失って知恵を得た
  - ルーン文字を発見
  - 戦死者をヴァルハラに集める
  - 変身の達人

#### トール (Thor)
- **役割**: 雷神、戦士の守護神
- **シンボル**: ミョルニル（雷神の槌）
- **特徴**:
  - 最も人気のある神
  - 巨人の天敵
  - 力と勇気の象徴
  - 赤髭の大男

#### フレイ (Freyr)
- **役割**: 豊穣、平和、繁栄の神
- **特徴**:
  - ヴァン神族から来た
  - 自分の剣を恋の代償に失う
  - ラグナロクで剣がないため敗れる

#### バルドル (Baldr)
- **役割**: 光明、美、善良さの神
- **特徴**:
  - 最も愛された神
  - 不死身だったがヤドリギで殺される
  - 彼の死がラグナロクの前兆

#### テュール (Tyr)
- **役割**: 戦争、正義、勇気の神
- **特徴**:
  - フェンリルを縛るために片手を失う
  - 古い戦神
  - 勇気と自己犠牲の象徴

### 女神

#### フリッグ (Frigg)
- オーディンの妻
- 結婚、母性、家庭の女神
- 未来を見通す力を持つ
- バルドルの母

#### フレイヤ (Freyja)
- 愛、美、魔術、戦争の女神
- ヴァン神族
- 戦死者の半分を受け取る
- 猫の引く車に乗る

#### イドゥン (Idun)
- 若さの女神
- 黄金のリンゴを守る
- 神々に不老を与える

### 悪しき存在

#### ロキ (Loki)
- **役割**: トリックスター、変身の達人
- **特徴**:
  - 巨人族の出身だが神々と兄弟の契り
  - 多くの問題を引き起こすが、解決もする
  - バルドルの死の黒幕
  - ラグナロクで神々に反逆
  - 三人の恐ろしい子供の父

#### ヘル (Hel)
- ロキの娘
- 冥界の支配者
- 半身が生者、半身が死者の姿

#### フェンリル (Fenrir)
- ロキの息子、巨大な狼
- ラグナロクでオーディンを飲み込む
- 神々の脅威として縛られる

#### ヨルムンガンド (Jormungandr)
- ロキの息子、巨大な蛇
- ミズガルズを取り囲む
- ラグナロクでトールと相打ち

## 主要な物語

### 創世神話
1. **ギンヌンガガプ**: 原初の虚空
2. **ユミル**: 最初の霜の巨人
3. **オーディンたちがユミルを殺し、世界を創造**
4. **アスクとエムブラ**: 最初の人間

### バルドルの死
- 最愛の神の死
- ロキの陰謀
- ヘルへの使者
- ロキの懲罰

### ラグナロク（神々の黄昏）
世界の終末と再生：

#### 前兆
- フィンブルの冬（3年間続く厳冬）
- 道徳の崩壊
- フェンリルとヨルムンガンドの解放

#### 最終戦争
- **オーディン vs フェンリル** → 両者死亡
- **トール vs ヨルムンガンド** → 相打ち
- **フレイ vs スルト** → フレイ敗北
- **ヘイムダル vs ロキ** → 相打ち

#### 破滅
- スルトの炎で世界が焼かれる
- 海に沈む大地
- ユグドラシルも揺らぐ

#### 再生
- 新しい大地が海から浮上
- 生き残った神々（ヴィーザル、ヴァーリ、モージ、マグニなど）
- ホズとバルドルが冥界から帰還
- 新しい人間の夫婦（リーヴとリーヴスラシル）
- より良い世界の始まり

## 北欧神話の特徴

### 運命の重視
- **ノルン**: 運命の三女神（ウルド、ヴェルザンディ、スクルド）
- 神々も運命に抗えない
- ラグナロクは避けられない

### 戦士の文化
- 戦死こそ名誉
- ヴァルハラ（戦死者の館）
- ヴァルキューレ（戦乙女）が戦死者を選ぶ

### 厳しい自然観
- 破滅的な世界観
- 神々も永遠ではない
- 常に脅威と戦う

### 実践的な知恵
- オーディンの智慧の言葉
- 生活の指針
- 名誉と勇気の重視

北欧神話は、厳しい自然環境で生きた人々の世界観を反映し、運命と勇気、そして世界の終わりと再生という普遍的なテーマを提示しています。
