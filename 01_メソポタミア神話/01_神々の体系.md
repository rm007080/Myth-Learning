# メソポタミア神話の神々

## 最高神クラスの神々

### アヌ (Anu / An)
- **役割**: 天空の最高神
- **シンボル**: 星、王冠
- **特徴**:
  - シュメール語で「天」を意味する
  - 神々の王として最高位に位置する
  - 後の時代にはエンリルやマルドゥクにその地位を譲る
  - ウルクの都市神

### エンリル (Enlil)
- **役割**: 大気・風・嵐の神、神々の王
- **シンボル**: 風、嵐
- **特徴**:
  - シュメール語で「風の主」を意味する
  - ニップルの都市神
  - 実質的な最高神として多くの神話で中心的役割
  - 人類に文明をもたらした
  - 大洪水を引き起こした神

### エア (Ea / Enki)
- **役割**: 知恵・水・創造の神
- **シンボル**: 水、魚、山羊
- **特徴**:
  - バビロニア名「エア」、シュメール名「エンキ」
  - 地下の淡水（アプスー）を支配
  - 人類の創造者で保護者
  - 魔術と知恵の神
  - エリドゥの都市神
  - ギルガメシュ叙事詩では人類を救う役割

## 主要な神々

### マルドゥク (Marduk)
- **役割**: バビロンの守護神、後の最高神
- **シンボル**: ドラゴン（ムシュフシュ）
- **特徴**:
  - バビロン第一王朝時代に最高神の地位を獲得
  - ティアマトを倒し世界を創造
  - 50の名前を持つ
  - エヌマ・エリシュの主人公

### イシュタル (Ishtar / Inanna)
- **役割**: 愛と美と戦争の女神
- **シンボル**: 金星、ライオン、八芒星
- **特徴**:
  - シュメール名「イナンナ」
  - 豊穣と性愛の女神
  - 戦いの女神でもある両面性
  - ウルクの守護女神
  - 「イナンナの冥界下り」の主人公
  - ギルガメシュ叙事詩にも登場

### シャマシュ (Shamash / Utu)
- **役割**: 太陽神、正義の神
- **シンボル**: 太陽円盤、光線
- **特徴**:
  - シュメール名「ウトゥ」
  - 昼間、世界を照らし全てを見る
  - 法と正義を司る
  - ハンムラビ法典の碑文に描かれる
  - ギルガメシュの守護神

### シン (Sin / Nanna)
- **役割**: 月神
- **シンボル**: 三日月、雄牛
- **特徴**:
  - シュメール名「ナンナ」
  - ウルの都市神
  - シャマシュとイシュタルの父
  - 時間と暦の計測に関連

## 創造に関わる原初の存在

### ティアマト (Tiamat)
- **役割**: 原初の海水、混沌の象徴
- **シンボル**: ドラゴン、海蛇
- **特徴**:
  - 女性原理、塩水の化身
  - アプスーの配偶者
  - 若い神々に反逆し、マルドゥクに倒される
  - その身体から世界が創造される

### アプスー (Apsu)
- **役割**: 原初の淡水
- **特徴**:
  - 男性原理
  - ティアマトとともに神々を生み出す
  - 若い神々の騒音に怒り、滅ぼそうとするがエアに殺される

## 冥界の神々

### エレシュキガル (Ereshkigal)
- **役割**: 冥界の女王
- **特徴**:
  - イシュタルの姉
  - 冥界（クル）を支配
  - 夫はネルガル

### ネルガル (Nergal)
- **役割**: 冥界の王、戦争と疫病の神
- **特徴**:
  - エレシュキガルの夫
  - 後に冥界の共同統治者となる

## その他の重要な神々

### ニンフルサグ (Ninhursag)
- **役割**: 大地母神、出産の女神
- **別名**: ニンマフ、ニントゥ
- **特徴**: 人類創造に関わる

### アダド (Adad / Ishkur)
- **役割**: 嵐と雷の神
- **シンボル**: 雷、雨
- **特徴**: 農業に不可欠な雨をもたらす

### ナブー (Nabu)
- **役割**: 書記と知恵の神
- **特徴**:
  - マルドゥクの息子
  - 文字と学問の守護神
  - 粘土板に人間の運命を記録

## 神々の関係図

```
【原初】
アプスー（淡水） + ティアマト（海水）
         ↓
【第一世代】
ラフム、ラハム → アンシャル、キシャル
         ↓
【最高神】
    アヌ（天空神）
    ↓
エンリル（大気神） ＋ ニンリル
    ↓
シン（月神）
    ↓
シャマシュ（太陽神）、イシュタル（金星神）

【別系統】
エア/エンキ（知恵・水の神）
    ↓
マルドゥク（バビロンの最高神）
    ↓
ナブー（書記の神）
```

## 神名の変遷

メソポタミアでは複数の文明が交代したため、同じ神が異なる名前で呼ばれることがあります：

| シュメール名 | アッカド/バビロニア名 | 役割 |
|-------------|---------------------|------|
| アン (An) | アヌ (Anu) | 天空神 |
| エンキ (Enki) | エア (Ea) | 知恵の神 |
| イナンナ (Inanna) | イシュタル (Ishtar) | 愛と戦争の女神 |
| ウトゥ (Utu) | シャマシュ (Shamash) | 太陽神 |
| ナンナ (Nanna) | シン (Sin) | 月神 |
| イシュクル (Ishkur) | アダド (Adad) | 嵐の神 |

## 神々の特徴

1. **擬人化された自然現象**: 多くの神は自然現象を司る
2. **都市神**: 各都市国家に守護神が存在
3. **家族関係**: 神々は結婚し、子を成す複雑な家族関係
4. **人間的性質**: 嫉妬、怒り、愛などの感情を持つ
5. **階層構造**: 明確な上下関係と役割分担

## 神々への崇拝

- **ジッグラト**: 神殿の塔、神々への崇拝の場
- **供物**: 食物、飲み物、香を捧げる
- **祭司**: 神々と人間の仲介者
- **祭儀**: 新年祭（アキトゥ）など重要な儀式
- **神像**: 神々の像が神殿に安置される

神々は人間に秩序と文明をもたらす存在であり、同時に恐れと畏敬の対象でした。
