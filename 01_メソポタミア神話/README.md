# メソポタミア神話

## 概要

メソポタミア神話は、世界最古の文明の一つであるメソポタミア文明（紀元前3000年頃〜）で生まれた神話体系です。現在のイラク地域、チグリス川とユーフラテス川の間の地域で発展しました。

## 時代背景

- **シュメール文明** (紀元前3000年頃〜紀元前2000年頃)
- **アッカド文明** (紀元前2350年頃〜紀元前2150年頃)
- **バビロニア文明** (紀元前1900年頃〜紀元前539年)
- **アッシリア文明** (紀元前2500年頃〜紀元前609年)

これらの文明が独自の神話を持ち、時代とともに融合していきました。

## 神話の特徴

1. **楔形文字による記録**: 粘土板に楔形文字で記された、現存する最古の文学作品群
2. **多神教**: 多数の神々が自然現象や社会的役割を司る
3. **創世神話**: 世界の始まりと神々の誕生を描く『エヌマ・エリシュ』
4. **英雄叙事詩**: 『ギルガメシュ叙事詩』など、人間の英雄を描いた物語

## 主要な文献

- **エヌマ・エリシュ** (Enuma Elish): バビロニアの創世神話
- **ギルガメシュ叙事詩** (Epic of Gilgamesh): 世界最古の文学作品の一つ
- **イナンナの冥界下り**: 女神イシュタル(イナンナ)の物語
- **アトラハシス叙事詩**: 人類創造と大洪水の物語

## 他の神話との関係

メソポタミア神話は後の多くの文化に影響を与えました：
- **旧約聖書**: 創世記の天地創造、ノアの方舟（大洪水）など
- **ギリシャ神話**: 神々の概念や英雄物語の形式
- **エジプト神話**: 交易を通じた文化交流
