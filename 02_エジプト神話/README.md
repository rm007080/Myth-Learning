# エジプト神話

## 概要

エジプト神話は、古代エジプト文明（紀元前3000年頃〜紀元前30年）で発展した神話体系です。ナイル川流域で栄えたこの文明は、約3000年にわたって独自の宗教と神話を築き上げました。

## 時代背景

- **初期王朝時代** (紀元前3100-2686年)
- **古王国時代** (紀元前2686-2181年) - ピラミッド建設の黄金期
- **中王国時代** (紀元前2055-1650年)
- **新王国時代** (紀元前1550-1077年) - 最盛期
- **末期王朝時代** (紀元前664-332年)
- **プトレマイオス朝** (紀元前332-30年) - ギリシャの影響

## 神話の特徴

1. **太陽崇拝**: 太陽神ラーを中心とした信仰
2. **死後の世界**: 来世と審判への強い関心
3. **動物の頭部**: 神々は人間の身体に動物の頭部を持つ
4. **ファラオの神性**: 王は神の化身（ホルス）とされる
5. **地域的多様性**: 各都市に独自の神々と神話体系

## 主要な宗教都市と神学

### ヘリオポリス（太陽の都）
- **主神**: ラー、アトゥム
- **神学**: 九柱神（エネアド）の体系
- **創世神話**: アトゥム-ラーから始まる創造

### メンフィス
- **主神**: プタハ
- **神学**: 言葉による創造
- **特徴**: 最も哲学的な創世神話

### テーベ
- **主神**: アメン（アモン）
- **時期**: 新王国時代の中心
- **融合**: アメン-ラーとして太陽神と融合

### アビドス
- **主神**: オシリス
- **重要性**: 死と再生の中心地
- **巡礼地**: エジプト最大の聖地

### ヘルモポリス
- **主神**: トート
- **神学**: 八柱神（オグドアド）の体系
- **特徴**: 四対の原初の神々

## 主要な文献

- **ピラミッド・テキスト** (古王国時代): 最古の宗教文書
- **棺テキスト** (中王国時代): 来世の呪文集
- **死者の書** (新王国時代): 冥界の旅のガイドブック
- **アムドゥアト**: 太陽神の夜の旅
- **門の書**: 冥界の12の門

## エジプト神話の独自性

### 死生観の特徴
エジプト神話の最大の特徴は、来世への深い関心です：
- **魂の複数性**: カー（生命力）、バー（霊魂）、アク（輝く霊）
- **肉体の保存**: ミイラ化の重要性
- **審判**: 心臓の計量による善悪の判定
- **永遠の生**: 来世での生活の継続

### 神々の融合（シンクレティズム）
- **ラー + アトゥム** = ラー・アトゥム
- **アメン + ラー** = アメン・ラー
- **プタハ + ソカル + オシリス** = プタハ・ソカル・オシリス
- **ラー + ホルアクティ** = ラー・ホルアクティ

政治的統合や神学的発展により、神々は融合し新しい形態を生み出しました。

## 神聖文字（ヒエログリフ）

エジプト神話は主に神聖文字（ヒエログリフ）で記録されました：
- **神殿の壁**: 神話の場面を描いた彫刻
- **パピルス文書**: 『死者の書』など
- **石碑**: 王の業績と神々への讃美
- **棺**: 来世への呪文

## 重要概念

### マアト（Maat）
- 真実、正義、秩序、調和の概念
- 宇宙の根本原理
- 女神マアトとしても擬人化
- ファラオの統治の基本原理

### イスフェト（Isfet）
- 混沌、無秩序、虚偽
- マアトの対立概念
- 常にマアトを脅かす存在

### デュアト（Duat）
- 冥界、死後の世界
- 太陽神が夜間に通過する場所
- 死者が審判を受け、永遠の生を得る場所

## 関連する他の文化

- **ヌビア**: 南方の隣国、エジプトの影響を強く受ける
- **リビア**: 西方の隣国
- **レヴァント**: 北東の地域、カナン、シリア
- **ギリシャ**: 後期にヘレニズム文化と融合
- **ローマ**: エジプト神話がローマ帝国に伝播
